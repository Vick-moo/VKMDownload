# VKMDownload 0.2.9

- 修复：Chrome 新版（155+）里扩展连不上应用，下载全部退回浏览器
- 修复：确认框会到前台；连续多个下载时文件名不再为空
- 修复：大小未知时不再显示「0 B」，已完成文件的进度显示正确
- 改进：进度列拆成两行（百分比 / 已下载大小），数字与单位不再被拆开
- 新增：历史保留期、日志开关、开机自启、关机延迟、完成后三选一
- 新增：设置页「浏览器扩展」配对面板与被拒诊断（写明原因）
- 新增：扩展的登录信息（Cookie）与无痕窗口开关；扩展弹窗改为只读状态显示
- 新增：托盘菜单（显示窗口 / 暂停全部 / 继续全部 / 限速 / 退出）
- 新增：任务右键菜单；排序、筛选与侧栏状态会被记住
- 新增：更新校验结果展示，旧版本备份可还原、可删除
- **扩展有改动，升级后请到 chrome://extensions 点一次「重新加载」；应用与扩展请一起更新**

## 详细说明

### 需要注意的兼容性

这一版修的是「应用与扩展对不上」的问题，**两端请一起更新到 0.2.9 / 1.0.4**：

- 应用 0.2.9 + 扩展 1.0.4：正常。
- 扩展还是 1.0.3：配对校验已能对上，但 1.0.3 仍是 11 个端口并发探测，
  部分 Chrome 上会把应用自己的应答饿到超时，仍可能间歇性显示「应用没有运行」；
  也看不到新的「登录信息」「无痕窗口」开关与只读弹窗。建议升到 1.0.4
  （应用只提示，不拒绝下载）。
- 应用还是 0.2.8 或更早：扩展会认为应用没有运行，下载退回浏览器（不丢文件）。

重新加载扩展的位置：浏览器地址栏进 `chrome://extensions`（Edge 为 `edge://extensions`），
找到 VKMDownload 点「重新加载」。若仍显示未运行，打开扩展弹窗点「重新配对」。

### 这一版修了什么

**下载列表与确认框**

- 浏览器点下载时，确认框会到前台，不再躲在浏览器后面；抢不到前台时闪任务栏。
- 连续多个下载时，第二个起确认框文件名不再为空：扩展会重试取文件名，
  仍取不到就用网址尾段，应用也会从网址派生一个占位名。
- 服务器不告诉文件大小时，大小不再显示成「0 B」，而是「未知」。
- 已完成但 0 字节的文件，大小列与进度列口径一致，进度条画满。
- 进度列拆成两行：上面百分比，下面已下载大小；数字和单位不会被拆到两行。
- 「开始选中」遇到已在下载或已完成的任务时，会说「已继续 N 个，跳过 M 个」，
  不再把「跳过」说成「继续失败」。

**设置与交互**

- 新增「历史保留期」（7/30/90 天或永久）、「日志开关」、「开机自启」、
  「关机延迟」（0–600 秒）、完成后动作三选一（打开目录 / 打开文件 / 不动作）。
- 任务行右键菜单：开始/继续、暂停、打开目录、复制链接、删除。
- 列表排序、类型筛选、侧栏折叠状态会被记住。
- 剪贴板链接检测间隔可低到 200ms；「按百分比保存」填 0 不再等于静默关闭。
- 「清除下载记录与日志」执行前会二次确认，写清删什么、不删什么。

**浏览器扩展**

- 新增「把登录信息交给下载器」开关（默认开）。关掉后扩展不读也不发 Cookie，
  应用收到旧扩展发来的 Cookie 也会丢弃。
- 新增「接管无痕窗口」开关（默认关）。
- 弹窗改为只读：显示是否在接管、扩展版本与应用要求的最低版本，不再提供开关
  （开关只在应用设置里改）。
- 设置页新增配对面板（配对状态、指纹、端口、重置配对）、扩展状态、
  被拒诊断列表，以及可选的 Origin 锁定。

**托盘与更新**

- 托盘菜单：显示窗口、暂停全部、继续全部、限速（不限速 / 1 / 5 / 10 MB/s）、退出。
- 更新面板显示校验结果（有没有哈希、大小是否一致、是否通过）与旧版本备份信息；
  备份可手动删除，「还原旧版本」仍然可用。确认成功后不再自动删备份。

### 安装

- 下载 `VKMDownload.exe`，放到一个可写目录直接运行（绿色版，无需安装）。
- 没有代码签名，首次运行 Windows SmartScreen 会提示；选「更多信息 → 仍要运行」。
- 扩展：`chrome://extensions` 开启开发者模式，「加载已解压的扩展程序」选择解压出来的
  `extension` 目录。**这一版必须重新加载**，不需要重新配对。

### 已知限制

- 托盘菜单与开机自启目前只有自动测试，真机交互仍需实际点一次确认。
- 无痕接管还要求浏览器允许扩展在无痕模式运行。
- 旧 popup（未重新加载扩展）点开关仍会收到应用的 405；重新加载后不再有开关。
- 部分文件站会限制多连接速度；遇到时在「新建下载」窗口把连接数设为 1 再添加
  （任务建好后，列表里目前不能单独修改连接数）。
- 首次配对仍依赖「应用端口没有被别的程序抢先占用」；更强的方案需要系统级注册，暂未实现。
